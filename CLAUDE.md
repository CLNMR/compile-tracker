# Compile Tracker — conventions

React 19 + Vite 7 + TypeScript, Firebase (Auth anonymous→Google or email/password via `linkWithPopup`/`linkWithCredential` in `src/store/authStore.ts`, Firestore, Hosting), PWA via vite-plugin-pwa. Spark plan only: no Cloud Functions.

- Path alias `@/` → `src/`. Strict TS, `verbatimModuleSyntax` (use `import type`).
- Styling: vanilla **CSS modules** (`*.module.css`) + design tokens in `src/styles/tokens.css`. No Tailwind. Fonts via `@fontsource/*` (Orbitron display, Inter body, JetBrains Mono terminal).
- All Firestore access goes through `src/repo/*`. UI never imports `firebase/firestore` directly (types excepted).
- Live data lives in zustand stores (`src/store/*`): one `onSnapshot` over all games; hooks in `src/hooks/*` are thin selectors.
- `src/stats/*` is pure (no React/Firebase imports) and unit-tested; stats are computed on read from `GameDoc[]`.
- Games never contain player names. Names are in `users/{uid}/players`; other users see `pseudonym(playerId)`.
- Guest mode (anonymous auth): no Players page, no Mine/All toggle (always All), no head-to-head or default player. The wizard skips the player step and uses the fixed side ids `GUEST_PLAYER_IDS` (`alpha`/`beta`, shown as Alpha/Beta). `src/stats/aggregate.ts` excludes guest ids from `byPlayer`/`h2h`.
- A valid game: 3 distinct protocols per side, 6 distinct overall, winner compiled all 3, loser 0–2. Winner-only games (`compileUnknown: true`) store the loser's `compiled` as empty and are excluded from every compile stat (`compileKnown()`; `Agg.compileKnown`, `compileDecks`, `compileGames` are the denominators). `buildGame()` in `src/repo/games.ts` enforces this client-side; `firestore.rules` enforces it server-side.
- Friends (Google or confirmed email accounts; rules' `realAccount()`, client `needsVerification` in the auth store): `handles/{handle}` + `profiles/{uid}`, mutual `users/{uid}/friends/{friendUid}` (`playerId` = my player for that friend; every friend has one, by default `players/friend_{friendUid}` named `@handle`, created by `ensureFriendPlayer` for friends who added me), and `users/{recipient}/offers/{gameId}` (owner writes sides, recipient sets `status`). Games stay unchanged; "Mine" = own games + accepted offers remapped by `src/stats/perspective.ts` (`sharedBy` marks them). After saving/deleting a game call `syncGameOffers`/`withdrawGameOffers` from `src/repo/offers.ts`.
- Scripts: `npm run dev`, `dev:emu`, `build`, `test`, `test:rules`, `emulators`, `deploy`; e2e against `dev:emu`: `e2e` (guest smoke), `e2e:friends` (two Google accounts), `e2e:email` (email sign-up, confirmation, reset). Auth email templates: `scripts/auth-emails.mjs` (`npm run auth-emails -- preview|push`).
- i18n: English + German. All user-visible text goes through `useT()` from `src/i18n` (`t('ns.key', params)`, `protocolName(id)`, `setShort(set)`, `number/percent/date/yearMonth`). Catalogues live in `src/i18n/messages/{en,de}/<namespace>.ts`; `de` is typed against `en` so a missing key fails `tsc`, and `src/i18n/i18n.test.ts` checks placeholder parity. Plurals: `key_one`/`key_other` + `{ count }`. Never render `ProtocolDef.name` directly; German protocol names are in `src/i18n/names.ts`. Locale: explicit choice in localStorage (`compile.locale`) → browser language → `en`. Non-React code uses `t`/`i18n()` from `@/i18n`.
- Analytics (`src/analytics/`): cookie-free Firestore counters `analytics/{day}/counters/{kind}_{source}` (kinds in `COUNTER_KINDS`, sources in `SOURCES`; both whitelisted in `firestore.rules`, keep in sync; `link` also bumps the all-time `analytics/total/counters/link` = non-anonymous accounts), Cloudflare beacon (`VITE_CF_BEACON_TOKEN`), and GA4 only after consent (`VITE_FB_MEASUREMENT_ID`, `useConsentStore`). Call `record*()` helpers from `@/analytics`; never import `firebase/analytics` elsewhere.
